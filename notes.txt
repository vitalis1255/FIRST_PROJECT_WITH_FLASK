course = next((c for c in COURSES if c["id"] == course_id)): Breaking it down:
for c in COURSES → go through each course in COURSES.
if c["id"] == course_id → check whether the course ID matches course_id.
c → represents the matching course.
next(...) → returns the first matching course.
course = → stores that course in the variable course.
